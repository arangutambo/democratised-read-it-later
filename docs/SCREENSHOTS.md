# Screenshots to take

Open the demo vault at `~/Documents/Demo Vault`, enable **Reader**, and drop a
document into `Sources/_decks/`. Save each shot to `docs/images/` with the
filename given; the README already references these paths.

Take them at a **1440×900-ish window** — wide enough that the reader and the note
sit side by side, small enough that text stays legible on a phone.

| # | File | What to capture | How to set it up |
| --- | --- | --- | --- |
| 1 | `hero-clip-to-note.png` | **The one that sells it.** A PDF open on the left with a visible yellow highlight; the companion note on the right showing that quote as a bullet with a sentence of your own prose nested underneath. | Open a text-heavy PDF page. Select a sentence, press `q`. Type a real sentence on the indented line. Split the pane so both are visible. |
| 2 | `library-tab.png` | The library with the four state counts across the top and a handful of rows showing titles, positions and progress bars. | Run **Open the Reader library in a tab**. Have 5–10 documents open at least once first so the counts and progress bars aren't all zero. |
| 3 | `video-transcript.png` | The video player above, timestamped transcript below, one transcript paragraph visibly selected. | Open a YouTube transcript document. Let the player load its thumbnail. Select a sentence in the transcript so the highlight shows. |
| 4 | `readwise-import.png` | The import dialog *after* selecting the CSV, so the plan line reads something like "2099 notes, 3443 skipped". | Run **Import from a Readwise export**, pick the CSV, and stop there — do not press Import. |

**Optional, if you want more:**

| File | What | Setup |
| --- | --- | --- |
| `nesting.png` | A note showing a parent image clip with two quotes nested under it and your writing under those | Clip a figure with `shift+r`, then two quotes with `q` |
| `excalidraw.png` | The clip gallery — thumbnails with tickboxes | Clip 3–4 figures, then **Send clips from this note to Excalidraw** |
| `transcription.png` | The transcription box showing `$$…$$` before you accept it | Enable AI, add a key, press `x`, drag a box around an equation |
| `settings.png` | The settings tab | Settings → Reader |

**Before you shoot:**

- Use the default Obsidian theme, so it looks like what a reviewer sees.
- Close the ribbon and any plugin you're not demonstrating.
- Nothing personal on screen — the demo vault has no real notes in it, which is
  the point of using it.
- PNG, not JPG. Crop to the Obsidian window, not the whole desktop.
